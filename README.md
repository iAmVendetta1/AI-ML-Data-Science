# AI · Machine Learning · Data Science

A living repository documenting my studies and applied projects across artificial intelligence, machine learning, and data science — developed in parallel with an M.S. in Artificial Intelligence at Maryville University.

Each folder represents a distinct area of focus, progressing from foundational AI concepts through applied deep learning.

---

## Repository Structure

### `IntroductoryAI/`
Foundational AI concepts including search algorithms, problem-solving agents, and classical AI techniques. Starting point for understanding how intelligent systems reason and make decisions.

### `Machine Learning/`
Supervised and unsupervised learning projects using Scikit-learn. Covers model training, train-test splitting, hyperparameter tuning, and evaluation metrics. Includes Matplotlib/Plotly visualizations to interpret model behavior and results.

### `Deep Learning/`
Neural network implementations using PyTorch and TensorFlow. Explores architecture design, backpropagation, activation functions, and training pipelines for classification and regression tasks.

### `Data-Science/`
Exploratory data analysis (EDA), feature engineering, and statistical analysis using Pandas, NumPy, and SciPy. Focuses on understanding data before modeling — cleaning, visualizing distributions, identifying patterns.

### `NimRL/`
Reinforcement learning implementation applied to the game of Nim. An agent learns optimal strategy through self-play, demonstrating core RL concepts: state representation, reward signals, and policy learning without explicit programming of rules.

### `TrackingScript.ipynb`
A utility notebook for tracking progress and notes across study topics.
